Usage · Chat

Chat with an agent.

Every conversation belongs to one agent and runs in one working directory. Pick the agent on the left, start a conversation, and type. This page covers the controls around the message box.

Agents and personas

An agent is a named assistant you own: a persona (Role definition), a working directory, a default model and optional IM bots. Create one under Settings → Agents → New Agent; you can have as many as you like, and each keeps its own conversations.

  • Role definition is sent with every turn — who the agent is, how it works, what it should care about. Longer, task-specific playbooks belong in skills.
  • Working directory is where the agent's commands run. It must sit inside your own home directory.
  • Default model is used for new web conversations and new IM threads; existing conversations keep theirs.

Model, account and thinking

The picker under the message box chooses the provider account, the model and the Thinking level (Default, Low, Medium, High, Max). The choice is saved with the conversation.

Locks after the first message

Provider and account can't change once the conversation has started — the session lives on that account. Start a new conversation to switch.

Working directory

A new conversation starts in the agent's working directory. To run it somewhere else, navigate to that folder in the workspace panel on the right before you send anything — the directory locks after the first message or upload.

Sending while it works

You don't have to wait for a reply to finish. A message sent while the agent is busy goes into a queue and runs after the current task; click × on a queued message to recall and edit it. On accounts that keep a resident session, a message can instead be inserted into the running task.

When every slot on the account is busy, the task shows Waiting for an account until one frees up.

When the agent asks you

An agent can stop and ask: a card titled Your input is needed appears with options (sometimes several may be picked) and a free-text answer. The agent continues once you submit. Question cards work on claude and codex accounts; claude-compatible accounts don't offer them.

Slash commands

DayMug doesn't interpret slash commands in the browser: whatever you type — /compact, a project's own commands — is passed to the CLI exactly as written. IM bots add a few of their own, such as /new on WeChat (see IM bots).

Pin, search and share

  • Pin to top keeps a conversation above the rest; the search box filters the list.
  • Share → Copy share link gives anyone with the link a view of the conversation; Unshare removes the link.
  • Conversations persist on the server, so the same list follows you to your phone or another browser.
