§ 01 — what you get

AI assistants that are yours — or everyone's.

Not a throwaway chat window — a place where your assistants live and every conversation is kept, whether you use it alone or share it with other people.

01 / 06 // shared

Set it up once, use it anywhere.

Give an assistant its name, its job and what it may touch — once. Use it from any device; if others join, they use the same one and nobody copies prompts around.

02 / 06 // live

Watch it work, step in any time.

See each step as it happens. Stop it, add a note mid-way, or pick the conversation up later on another device.

03 / 06 // chat apps

Lives in your chat app.

Connect your own Slack or Feishu bot (Telegram and WeChat work too) and ask it in a direct message or a group.

04 / 06 // scheduled

Runs on a timer.

Daily report at 9:00, weekly summary on Friday — set it once, and the result is posted to your chat.

05 / 06 // anywhere

Any device, nothing to install.

It's a website. Start on your laptop, check in from your phone — it's the same conversation.

06 / 06 // yours

Your computer, your accounts.

Everything is stored on the computer you chose. Use the AI plan you already pay for, or an API key. Free and open source.

§ 03 — get started

From zero to your first chat, in six steps.

Steps 1–3 happen once, on one computer, and take about five minutes. Everything after that is done in the browser.

  1. 1

    Pick a computer to run it

    A Mac or a Linux machine that stays on — an office server, a cloud VM, even a spare Mac mini. Only this computer installs anything; every other device just uses a browser.

    You also need: Node.js 18+ on that computer, and an AI subscription (or an API key) — Claude, Codex or any compatible endpoint.

  2. 2

    Run the installer

    Open Terminal on that computer and paste this line. It sets everything up and starts DayMug — no need to be root.

    linux  — in Terminal 
    $ curl -fsSL https://github.com/DayMug/DayMug/releases/latest/download/install.sh | bash
    macOS  — in Terminal · Apple Silicon 
    $ curl -fsSL https://github.com/DayMug/DayMug/releases/latest/download/install.sh | bash
  3. 3

    Open it and create your account

    Go to http://127.0.0.1:8090 in a browser on that computer. The first person to open it creates the admin account.

  4. 4

    Connect your AI

    Add the AI account you already pay for, click Log in and approve in the browser — or paste an API key. Then add the model you want to use.

    Settings → Administration → Providers & models

  5. 5

    Create your first assistant

    Give it a name, say what it's for, and pick the folder it works in. Then open a chat and ask it something.

    Settings → Agents → New Agent

  6. 6

    Optional: share it

    Using it on your own? You are done. To reach it from elsewhere or let other people in, put it on your network, behind a tunnel or on your own domain (how to), then add people by name or let them sign in with SSO.

    Settings → Administration → Users

Then, when you're ready Put an assistant in Slack or Feishu → Run an agent on a schedule → All docs →
§ 04 — questions

Frequently brewed.

Short answers. If yours isn't here, ask us.

Q.01 Do other devices or people need to install anything?

No. Your other devices — and anyone you share it with — open a link in the browser or on the phone, or talk to the bot in Slack or Feishu. Only the one computer that runs DayMug installs it.

Q.02 Do I need to pay for the AI?

DayMug itself is free. It uses the AI plan — or the API key — you already have. We don't sell credits.

Q.03 Where is our data stored?

On the computer you installed it on. DayMug has no tracking; it only talks to the AI service and the chat apps you connect.

Q.04 Can several people share one AI account?

Yes. When the account is busy, the next request waits in a visible queue. You can also give each person their own account. Check your AI provider's terms for how a plan may be shared.

Q.05 Does it work on Windows?

On Windows, just use the browser. The computer that runs DayMug needs to be a Mac or Linux machine.

Q.06 Is it open source?

Yes — everything is on GitHub. The license is Apache 2.0 with one extra rule: if you offer DayMug to others, keep the "Powered by DayMug" note visible.
